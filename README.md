# Dashchan Ejchan Extension

Расширение **Ежчан** для [Dashchan Fork](https://github.com/TrixiEther/DashchanFork).

## Возможности

- домены `ejchan.net` и `ejchan.site`;
- выбор активного домена в настройках расширения;
- прохождение Anubis для `ejchan.site` через WebView с автоматическим обновлением cookies;
- понятное сообщение, если `ejchan.site` открыт не с российского IP;
- Е-Пропуск с отдельным хранением для каждого домена;
- доски, треды, каталог, постинг, файлы, капча и жалобы;
- автоматическое обновление через встроенный механизм Dashchan;
- outline-иконка Ежчана в списке форумов.

## Установка

1. Откройте раздел **Releases**.
2. Скачайте APK последней версии.
3. Установите APK и включите Ежчан в Dashchan Fork.

После установки новые версии обнаруживаются самим Dashchan по `update/data.json`.
Все релизы подписываются одним ключом. APK из других источников с другой подписью поверх этой версии не установится.

## Выпуск новой версии

Создайте и отправьте тег вида `v1.3.0`. GitHub Actions:

1. соберёт подписанный APK;
2. создаст GitHub Release;
3. загрузит APK и SHA-256;
4. обновит `update/data.json` в ветке `main`.
